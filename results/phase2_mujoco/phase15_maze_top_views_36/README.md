# Saved Phase 1.5 maze top views

This package contains all 36 existing fit mazes used by the completed Phase 2 comparison: 12 each from R, BP, and M. The maze geometry, start, and goal were read from the corresponding saved candidate records. No maze generation or experiment execution occurred.

Start is marked cyan (S); goal is gold (G). Coordinates are saved grid `(x, y)` values; positive y is shown upward. See `overview_all_36.png` for the full contact sheet, `overview_R.png`, `overview_BP.png`, and `overview_M.png` for method sheets, and `metadata.json` for identities and source hashes. Individual diagrams are in the R, BP, and M folders.
